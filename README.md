# 轻友

![轻友软件封面](assets/branding/qingyou-cover.png)

一个松弛、自然的微信 PC 智能回复助手。它会理解上下文与图片，逐渐适应联系人的表达习惯，
再用更接近真人的节奏回复。重要或拿不准的消息会进入手动队列，由你亲自处理。

---

## 功能一览

- **大模型底座，API 调用**：支持 **DeepSeek** 与 **豆包（火山方舟）** 两种 OpenAI 兼容接口（按要求仅内置这两家）
- **选择聊天对象**：从微信当前会话列表勾选；可为每个对象设置「关系」（女朋友/老板/妈妈…），大模型会据此把握语气分寸
- **意图分析 + 最优回复**：每条消息先分析对方的目的与情绪，再结合历史对话生成最合适的回复
- **情商智商双在线**：先接住情绪再给内容；不确定的信息不编造；口语化、像真人；可穿插微信自带表情（[捂脸] [憨笑]…）
- **表情包**：`assets/stickers/` 下按分类放图（开心/摸鱼/卖萌…），大模型自动选择合适时机随机发送
- **表情包文字识别**：收到表情包时先识别画面文字；有字按文字理解，无字再按图片、动作与情绪理解
- **拟人化**：随机延迟、长回复拆分、连续消息合并，并逐渐学习对方的短句、语气词、标点和笑声习惯
- **隐私友好的语气画像**：只在本地保存统计特征，不额外复制保存联系人原文
- **记忆**：每个联系人独立保存双方对话上下文，重启后仍能延续话题
- **轻松界面**：柔和自然色、圆润操作按钮与连续分区布局
- **转人工**：文件默认进入手动队列；视频可选自动看封面或手动处理；借钱、纠纷等复杂情况也会主动转人工
- **模拟测试**：不真发消息，先看看大模型会怎么回

## 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 |
| 微信 | PC 版微信 4.x（wxauto4 支持 4.0.5 ~ 4.1.x，实测 4.1.13.12 可用） |
| Python | **3.9 ~ 3.13**（wxauto4 官方只发布到 3.13；本机已装 3.13，与你的 3.14 共存） |
| 依赖 | wxauto4、requests（`安装依赖.bat` 一键安装） |

## 快速开始

1. **安装依赖**：双击 `安装依赖.bat`
2. **申请 API Key**（二选一，或都配）：
   - DeepSeek：https://platform.deepseek.com/api_keys
   - 豆包（火山方舟）：https://console.volcengine.com/ark 开通方舟、创建推理接入点或直接用模型 ID（如 `doubao-seed-1-6-250615`）
3. **启动**：双击 `启动.bat`
4. **连接微信**：点击「连接微信」（微信需已登录；主窗口收起到托盘时软件会自动恢复）
5. **选人**：在「聊天对象」页左侧会话列表多选 → 填写关系 → 「添加所选会话 →」
6. **配置模型**：在「大模型设置」页选供应商、粘贴 API Key → 点「测试连接」
7. **开始**：回到顶部点击「开始自动回复」

## 消息类型策略（回复设置页可改）

| 类型 | 默认 | 说明 |
|---|---|---|
| 文字 / 引用 / 链接 | 自动 | 大模型正常回复 |
| 表情包 | 自动 | 视觉模型先识别文字，无文字再理解图片情绪 |
| 语音 | 自动 | 尝试语音转文字；失败则礼貌回应 |
| 视频 | 手动 | 可切换为自动；自动时仅依据视频封面做保守判断 |
| 图片 | 自动 | 开启视觉模型后分析画面内容；关闭时按图片消息处理 |
| 文件 / 其他 | 手动 | 进入待手动队列 |

## 常见问题

- **提示"未找到已登录的客户端主窗口"**：微信主窗口被收起到托盘了。软件会自动恢复；
  若仍失败，请手动打开微信主窗口（不能只挂在托盘）后重试。
- **回复太慢/太快**：调整「回复设置」里的延迟区间；轮询间隔默认 1 秒。
- **想让它看懂图片**：回复设置里把「图片」改为自动，并在大模型设置里启用视觉模型
  （豆包填 `doubao-seed-1-6-250615` 等多模态模型；DeepSeek 暂不支持看图）。
- **表情包发不出去**：表情包目录还是空的。往 `assets/stickers/开心/` 等分类文件夹里放几张
  jpg/png/gif 即可；没图时大模型只用文字表情代码。
- **界面开了但连不上微信**：确认 `py -3.13 -c "import wxauto4"` 不报错；
  若你的电脑没有 Python 3.13，先从 python.org 安装（安装时勾选 py launcher）。
- **监听过程中别动微信主窗口**：消息读取依赖微信窗口的控件树，最小化主窗口会导致读取失败
  （软件会自动重连）。
